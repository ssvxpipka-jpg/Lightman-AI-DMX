# Lightman

**Быстрый инструмент для световика, которому не нужна ещё одна консоль на 20 кг.**

Open-source приложение для управления светом на малых площадках и в прокате. Desktop, macOS (Apple Silicon), Python + PySide6. AI-ассистент видит 3D-сцену и может ей управлять. Без сервера, без аккаунтов, без телеметрии — всё локально.

---

### Суть

Lightman — это десктопное приложение для управления светом на небольших площадках: школьные залы, театры, прокат. Вместо тяжёлой консоли — ноутбук, 3D-вьюпорт и AI-ассистент, который видит сцену и понимает, что происходит.

Всё работает **локально**. Никаких серверов, аккаунтов, облачной телеметрии. Твои сцены, скрипты и база знаний не покидают машину.

### Возможности

**Director — AI-чат**

- LLM на выбор: Groq, OpenRouter, Gemini, Mistral, Cerebras, любой OpenAI-совместимый endpoint (включая локальные Ollama и LM Studio)
- AI видит текущую сцену: приборы, позиции, интенсивности, dead zones
- Может спавнить и удалять приборы через скрытые маркеры `[SPAWN: …]` / `[REMOVE: …]` — оператор видит только результат, не маркеры

**Три режима автономности AI** (Settings → AI Mode; влияют и на промпт, и на поведение)

- 🟢 **Easy** — AI предлагает, под ответом кнопки ✅ / ❌, решает оператор
- 🟡 **Medium** — AI применяет рутину сам, 10 секунд висит кнопка **Undo**
- 🔴 **Hard** — AI применяет мгновенно, без undo. Остановить может только Blackout

**Studio 3D**

- Real-time OpenGL вьюпорт (pyqtgraph)
- Приборы, фермы (truss / stand / box), dead zones
- Интенсивность 0–100 на прибор — сейчас управляет прозрачностью меша, позже пойдёт в реальный DMX
- Клик — выделить, ластик — удалить
- Сохранение/загрузка сцены в `data/scene.json`

**Blackout — абсолютный override**

- `Esc` или кнопка ⬛ **Blackout** → мгновенный LOCK
- Замораживает: чат, Settings, AI spawn/remove
- Дежурный свет (work light) уходит на **2 %** — сцена не гаснет полностью
- AI **не может** отменить, продолжить или предложить продолжить Blackout
- ▶ **Resume** возвращает каждому прибору его интенсивность до блэкаута
- Если хоть один прибор не ушёл в 0 % — LOCK **не включается**, оператор получает предупреждение в Session Log

**Dead zones — жёсткий no-fly list**

- Лазеры и яркие лучи никогда не направляются в bounding box мёртвой зоны
- Правило вшито в системный промпт AI и видно в 3D
- Лазеры в dead zones запрещены на уровне архитектуры

**Auth и оболочка**

- Локальный логин / регистрация (JSON, без сервера)
- Шесть табов: Director · Studio 3D · Timeline · Script · Rehearsals · Profile
- Session Log внизу с цветным логом событий
- UI на английском и русском
- Тёмная тема в стиле DaVinci, акцент `#ff8a00`

**Локальное обучение AI (RAG)**

- База знаний на сценарии шоу и каталоге приборов
- Эмбеддинги через `DefaultEmbeddingFunction` — **без OpenAI-ключа**
- Хранилище: `.lightman_cache/rag`
- Текст не покидает машину

### Установка

**Из `.dmg` (Apple Silicon: M1 / M2 / M3 / M4)**

- Минимум macOS 12 Monterey
- Ad-hoc подпись → Gatekeeper ругается на первый запуск. Одна команда:

```bash
xattr -cr /Applications/Lightman.app
```

**Из исходников**

```bash
python src/director/main.py
```

### Технологии

- Python 3.10+ (тестировали на 3.11)
- PySide6, pyqtgraph, OpenGL
- LangGraph + LangChain Core
- ChromaDB (локальный RAG)
- PyInstaller + dmgbuild (сборка `.dmg`)

### Структура репозитория

```

├── src/director/

│   ├── ui_3d.py              # OpenGL вьюпорт
│   ├── theme.qss             # тёмная тема
│   └── studio_3d/            # вкладка 3D: панели, тулзы
├── shared/
│   ├── auth.py               # локальный логин
│   ├── rag_init.py           # база знаний
│   ├── agents_config.py      # LangGraph: director + специалисты
│   └── i18n.py               # переводы
├── fixtures_db/
│   └── fixtures_catalog.json
└── data/
    ├── script.txt            # опционально, идёт в RAG
    └── settings.json         # создаётся при сохранении (в .gitignore)
```
