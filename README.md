# 🎭 Lightman — AI Stage Lighting Automation

**[🇷🇺 Русская версия] | [🇬🇧 English version](README_EN.md)**

**Lightman** — это полностью бесплатная (Open Source) экосистема для автоматизации сценического света на базе искусственного интеллекта. Забудьте про ручное сведение лучей — ИИ сам проследит за актерами, подстроится под музыку и поймет сценарий.

## ✨ Что умеет Lightman?
*   🖥 **Director (Мозг)**: Темный интерфейс в стиле DaVinci Resolve, 3D-сцена с расстановкой приборов, AI-чат, таймлайн сцен.
*   🧠 **Умный ИИ (BYOK)**: Подключение к любому облачному провайдеру через ваш API-ключ (никаких подписок).
*   📚 **Локальное обучение (RAG)**: Загрузите сценарий и приборы — нейросеть обучится на них *мгновенно* и бесплатно прямо на вашем компьютере.
*   🎵 **Sound (Уши)**: Анализ системного звука (BlackHole), вычисление BPM и битов, передача по OSC.
*   💡 **Light (Руки)**: Подключение напрямую к ОС пультов (Titan OS, grandMA3 OS, ChamSys OS, ETC Eos OS, QLC+ OS).

## 🚀 Установка (macOS)
Для пользователей Mac мы собрали готовые установщики!

1. Перейдите в раздел **[Releases](https://github.com/ssvxpuk/lightman/releases)**.
2. Скачайте файлы:
   * `Lightman.dmg` (Главное приложение)
   * `LightmanSound.dmg` (Приложение для звукаря)
   * `LightmanLight.dmg` (Приложение для пульта)
3. Откройте `.dmg` и перетащите приложения в папку **Applications**.
4. *Примечание:* Если macOS ругается, что "Приложение повреждено", выполните в терминале: `xattr -cr /Applications/Lightman.app`.

### 🐧 Windows и Linux
Готовых `.exe` и `.deb` пока нет, но вы можете собрать их сами из исходников:
*   **Windows**: Установите Python 3.12, выполните `pip install -r requirements.txt` и запустите `scripts\build_win.bat`.
*   **Linux**: Запустите `bash scripts/build_linux.sh`.

## 🧠 Как настроить ИИ (BYOK)
Мы не берем денег за использование ИИ. Вы используете свой ключ (Bring Your Own Key). Это быстро и бесплатно.

1. Зарегистрируйтесь у любого бесплатного провайдера:
   * **[Groq](https://console.groq.com)** (Самый быстрый, без карты)
   * **[OpenRouter](https://openrouter.ai)** (Есть бесплатные модели)
   * **[ZvenoAI](https://zveno.ai)** (Работает в РФ без VPN)
2. Скопируйте API-ключ.
3. В приложении **Director** нажмите **⚙ Settings** -> вкладка **AI Provider**.
4. Вставьте ключ и нажмите **Save**.
*Окошко подтвердит, что нейросеть обучилась на ваших приборах.*

## 🛠 Технологии
*   **UI**: PySide6 + PyQtGraph (OpenGL)
*   **AI**: LangGraph + ChatOpenAI (BYOK)
*   **RAG (Память)**: ChromaDB (Локально, без облака)
*   **Звук**: Librosa + Sounddevice
*   **Сеть**: Python-OSC
